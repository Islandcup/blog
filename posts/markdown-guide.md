Markdown 是最流行的轻量级标记语言之一，几乎成为了写作的标准格式。无论你是写博客、写文档还是记笔记，掌握 Markdown 都能让你的写作效率倍增。

## 什么是 Markdown

Markdown 由 John Gruber 于 2004 年创造，其核心理念是：**易读易写**。即使在没有渲染工具的情况下，Markdown 文档也是可读的纯文本。

## 基本语法

### 标题

使用 `#` 号表示标题，一个 `#` 代表一级标题，最多六个：

```markdown
# 一级标题
## 二级标题
### 三级标题
```

### 文本样式

```markdown
**粗体**  *斜体*  ~~删除线~~  `行内代码`
```

**粗体**  *斜体*  ~~删除线~~  `行内代码`

### 列表

无序列表用 `-`、`*` 或 `+`，有序列表用数字加点：

```markdown
- 项目一
- 项目二
  - 子项目

1. 第一步
2. 第二步
```

### 链接与图片

```markdown
[链接文字](https://example.com)
![图片描述](image.jpg)
```

### 代码块

使用三个反引号包裹代码块，可以指定语言实现语法高亮：

```python
def hello():
    print("Hello, World!")
```

### 引用

```markdown
> 这是一段引用文字
> 可以跨多行
```

> 这是一段引用文字

## 进阶技巧

### 表格

```markdown
| 语法 | 说明 |
|------|------|
| **粗体** | 强调 |
| `代码` | 行内代码 |
```

| 语法 | 说明 |
|------|------|
| **粗体** | 强调 |
| `代码` | 行内代码 |

### 任务列表

```markdown
- [x] 已完成任务
- [ ] 待办任务
```

- [x] 已完成任务
- [ ] 待办任务

## 总结

Markdown 的学习曲线近乎为零，但它的表达能力却非常强大。掌握它之后，你会发现在各种场景下写作都变得无比顺畅。
