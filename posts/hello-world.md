每一个博客的开始，都像是一只幼虫破茧而出的瞬间。

这里是 **虫巢** —— 我在这片数字森林里搭建的一个小小的巢穴，用来安放我的思绪、笔记和偶尔的奇思妙想。

为什么叫「虫巢」？因为我深信灵感像萤火虫一样，稍纵即逝。如果不及时捕捉、记录下来，它们就会消失在夜色中。而这个博客，就是我为这些「萤火虫」们准备的家。

## 为什么写博客

写博客的原因有很多：

- **记录成长**：把自己的思考和知识沉淀下来，让未来的自己看看今天的模样。
- **分享交流**：也许某个观点或经验能帮到屏幕另一端的你。
- **对抗遗忘**：好记性不如烂笔头，这句话永远不过时。

## 关于这个网站

这个博客是用纯静态技术构建的，没有复杂的后端，所有内容都在前端渲染。它可以直接部署在任何静态托管服务上——比如 GitHub Pages。

目前的实现方式如下：

- 文章数据存储在单独的 `.md` 文件中
- 首页动态渲染文章列表和摘要
- 每篇文章通过 `post.html?id=xxx` 查看完整内容
- 纯 CSS 实现深色模式自适应

## 接下来会写什么

2. 读书笔记与读后感
